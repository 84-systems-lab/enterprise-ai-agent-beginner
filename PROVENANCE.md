# Source map

This companion contains the complete application source used in the book.
Python package identifiers such as askanydoc_rag remain consistent across
imports. The fictional company and sample records are teaching resources.

SOURCE_MANIFEST.json identifies the distributed files by relative path and
SHA-256. CHECKPOINTS.json identifies the source and chapter resource archives.
Installed packages, credentials, Terraform state, plans and private documents
are excluded. Configure your own service connections as explained in the book.

The application uses the private AWS RAG path, delegated live SharePoint and
structured Salesforce reads as separate adapters. Neither live source is
silently copied into the AWS index. NOTICE.md identifies third-party components.
